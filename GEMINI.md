# Grow More Nursery Clone

## Project Overview
A clone of growmorenursery.com focusing on high-quality visuals, responsive design, and functional sections.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)

## Design System
- **Colors:**

  - Secondary: #ffffff (White)
  - Background: #f5f5f5 (Light Gray)

- **Typography:**
